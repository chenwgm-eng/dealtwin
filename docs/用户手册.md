# 白泽 BaiZe — 智能销售策略引擎 用户手册

## 1. 产品概述

**白泽（BaiZe）** 是一款面向 B2B 销售的智能策略引擎，通过数字孪生技术对销售项目进行全生命周期管理。系统以**商机**为核心，围绕**客户组织架构**、**干系人关系网络**、**销售阶段推进**和**AI 智能推演**四大支柱，帮助销售团队识别盲区、制定策略、模拟推演、提升赢单率。

### 核心能力

| 能力 | 说明 |
|---|---|
| **商机全生命周期管理** | 从线索到赢单/丢单的六阶段追踪，含阶段退出条件检查 |
| **客户组织洞察** | 客户工商信息自动检索、组织架构图、联系人管理 |
| **干系人关系建模** | 干系人画像（角色/支持度/决策力/紧迫感）、汇报关系、影响网络 |
| **AI 盲区扫描** | 基于项目数据自动发现信息缺口、风险点、机会点 |
| **行动建议引擎** | 根据当前阶段和干系人态势生成下一步最佳行动 |
| **拜访预案生成** | 针对特定干系人或议题，AI 自动生成结构化拜访预案 |
| **闭门发酵推演** | 模拟会后干系人私下互动和态度演变，预测信息扩散趋势 |
| **虚拟干系人采访** | 基于推演历史，以干系人第一人称视角回答问题 |
| **自进化学习引擎** | 从采纳/拒绝的行动中提取模式，持续优化推荐质量 |

## 3. 功能详解

### 3.1 仪表盘

仪表盘是全局视角的销售业绩总览页面，包含以下模块：

**关键指标卡片**
- 活跃商机数量、赢单金额、丢单金额、赢单率
- 商机金额按三阶段（线索 → 商机 → 赢单）明细展示
- 点击金额卡片可跳转至商机台账查看对应项目列表

**重点关注事项**
- 今日到期待办、待识别干系人、红色状态联系人、未审阅拜访预案
- 每类事项可点击跳转至具体项目

**AI 智能洞察**
- 基于时间范围内的销售数据，AI 生成态势分析
- 包含风险预警、机会提示、优先级行动建议
- 支持手动刷新，可切换时间范围（本周/本月/本季度/本年/自定义）

### 3.2 客户管理

**客户列表**
- 以树形结构展示客户（含父子关系、子公司）
- 支持新建客户、合并客户
- 点击客户进入客户详情

**客户档案（客户概览）**
- **工商注册信息**：统一社会信用代码、法定代表人、注册资本、成立日期、企业类型、经营状态、经营范围、注册地址、办公地址
- **业务信息**：所处行业、员工规模、营收规模、分支机构、发展历程
- 支持 LLM 自动检索工商信息（点击「LLM 检索」按钮）
- 所有字段支持双击编辑

**客户概览**
- AI 生成的客户概述文本（基于客户档案）
- 支持「AI 生成」和「AI 优化排版」
- 图谱节点以 3-3-3 战略项为准

**联系人管理**
- 联系人列表（姓名、部门、职位、电话、邮箱）
- 汇报关系（指向其他联系人）
- **网络检索潜在联系人**：实时联网搜索公司关联人员，勾选后一键入库
- 支持新建、编辑、删除联系人

**客户商机**
- 展示该客户及子公司关联的所有商机项目

**组织架构**
- 客户联系人组织架构图可视化

### 3.3 商机台账

商机看板按销售阶段分列展示：

| 阶段 | 说明 |
|---|---|
| 线索（Suspect） | 客户编排、商机识别，OM10 Bid/No-Go |
| 商机确认（Identity） | 干系人识别、需求确认，OM20 Go/No-Go |
| 方案定义（Define） | 方案设计、投标策略，OM30/OM40 |
| 商务确认（Confirm） | 商务谈判、合同签署，OM70 |
| 赢单（Closed Won） | 已签约 |
| 丢单（Closed Lost） | 已关闭 |

**操作**
- 拖拽卡片到目标阶段完成阶段切换（需确认）
- 点击卡片进入项目详情
- 支持新建商机、编辑商机、删除商机

### 3.4 商机概览

选中项目后首先看到的页面，展示项目核心信息：

- **基本信息**：商机名称、客户名称、预算、行业、预计关闭日期、时间确定性、预算确定性、倾向性
- **公司愿景 & 业务痛点**：支持双击编辑
- **阶段交付物**：当前阶段需完成的交付物清单，支持手动勾选确认、附件上传/下载
- **阶段退出条件检查**：点击「阶段检查」按钮，AI 评估是否满足推进条件
- **关键干系人摘要**：当前阶段重点关注干系人
- **右侧图谱侧栏**：干系人关系网络缩略图

### 3.5 商机历程

时间线形式展示项目从创建到当前的所有阶段变更记录，包括：
- 变更时间
- 变更前/后阶段
- 变更原因

### 3.6 商机图谱

以可视化关系图展示：
- **干系人节点**：按角色着色（推动者/阻碍者/引导者/冠军/怀疑者/教练）
- **关系连线**：汇报关系、盟友、朋友、导师、竞争、冲突
- **节点大小**：反映决策力权重
- 点击节点查看干系人详情
- 支持缩放、拖拽、全屏

### 3.7 商机干系人

干系人是推演模拟的核心数据来源，每个干系人包含以下属性：

| 属性 | 说明 |
|---|---|
| 姓名 | 干系人姓名 |
| 职位 | 在客户组织中的职位 |
| 职级 | 高管 / 中层 / 基层 / 未填写 |
| 项目角色 | 技术买家 / 业务买家 / 财务买家 / 影响者 / 决策者 / 使用者（悬浮查看角色说明） |
| 采购角色 | 推动者 / 阻碍者 / 引导者 / 冠军 / 怀疑者 / 教练（行为定位） |
| 决策影响力 | 0-10 分 |
| 支持度 | 0-10 分（对项目的支持程度） |
| 紧迫感 | 0-10 分 |
| 职责范围 | 自由文本 |
| 个人动机 | 自由文本 |
| 汇报对象 | 指向同项目内另一个干系人 |
| 识别状态 | 已确认 / 待识别 |

**操作**
- 添加干系人、编辑干系人、删除干系人
- 关联联系人：将干系人与客户联系人关联
- 添加第三方干系人：不需要关联联系人的临时干系人
- 合并干系人：合并重复条目
- 状态变更日志：记录所有手动修改的变更原因

### 3.8 销售工作台

工作台按照销售闭环顺序组织，从左到右依次为：

#### 盲区扫描

点击「扫描盲区」按钮，AI 分析当前项目数据，输出：
- **综合健康评分**（0-100 分）
- **盲区发现列表**（按严重程度分级：critical / warning / info）
- 每项发现包含问题描述和 AI 建议
- 自动扫描（Agent 定时任务）和手动扫描两种方式

#### 行动建议

AI 根据当前阶段和干系人态势，推荐下一步行动：
- 每条行动包含类型、优先级、关联干系人、建议内容
- 可**采纳**（转化为待办任务）或**拒绝**（标记为不适用，选择拒绝原因）
- 采纳/拒绝操作会反馈至自进化引擎

#### 待办事项

项目管理任务列表：
- 任务类型：盲区跟进、答疑解惑、建立联盟、提供材料、会议安排、后续跟进
- 任务状态：待处理 / 进行中 / 已完成
- 支持新建、编辑、删除、排序（AI 智能排序）
- 关联干系人（支持多选）
- 截止日期、优先级

#### 拜访预案

针对特定干系人或议题，AI 生成结构化拜访预案：
- 选择目标干系人、会议类型（初次拜访/方案汇报/异议处理/关系维护）
- 关联待办事项和资料
- AI 生成预案内容（议题、话术、风险提示等）
- 预案状态：待生成 / 已生成 / 已审阅

#### 拜访记录

会议/拜访后的记录管理：
- 记录会议内容、干系人反馈
- 关联待办事项和拜访预案
- 支持附件上传
- 自动解析干系人态度变化建议

### 3.9 推演模拟（闭门发酵）

这是系统的核心差异化功能，模拟会议结束后干系人私下互动和态度演变。

**操作流程**

1. **选择输入**（01 会议纪要）：勾选相关的拜访记录作为发酵起点
2. **选择触发条件**（02 关联任务）：勾选相关的待办事项作为影响因子
3. **启动推演**：点击「启动推演」按钮，系统将运行 3 轮扩散模拟

**输出结果**

- **推演时间线**：每轮扩散的叙事描述、互动事件、态度变化
  - 第 0 轮：会议结束时的初始状态
  - 第 1-3 轮：逐轮扩散的互动和态度演变
- **态度变化曲线**：可视化展示各干系人支持度变化趋势
- **推演结论**：整体趋势判断、变化最大干系人、互动统计

**后续操作**

- **查看报告**：AI 生成结构化推演分析报告（推演概述 → 干系人分析 → 风险预警 → 机会洞察 → 行动建议）
- **虚拟采访**：选择任意干系人，以第一人称视角提问，AI 基于推演历史模拟其回答
- **重新推演**：清空结果，调整输入参数后重新推演

### 3.10 智能进化（学习中心）

自进化引擎的模式审核台：
- 系统从采纳/拒绝的行动中自动提取销售模式
- 候选模式在此展示，等待人工审核
- **审核通过**：模式进入推荐引擎，影响后续行动建议
- **废弃**：模式标记为废弃，不再使用
- 推荐引擎保持 20% 探索配额（Exploration），确保推荐多样性

### 3.11 Agent 任务

管理后台定时任务：
- 查看所有 Agent 任务列表及状态
- 暂停/恢复/立即运行任务
- 更新任务调度规则

## 4. 典型工作流程

### 4.1 新建商机并推进

```
1. 客户管理 → 新建客户 → 填写工商信息/业务信息
2. 客户档案 → 网络检索联系人 → 导入联系人
3. 商机台账 → 新建商机 → 关联客户 → 填写基本信息
4. 商机干系人 → 添加干系人 → 设置角色/支持度/汇报关系
5. 销售工作台 → 盲区扫描 → 查看发现 → 采纳行动建议
6. 销售工作台 → 待办事项 → 执行任务
7. 销售工作台 → 拜访预案 → 生成预案 → 执行拜访
8. 销售工作台 → 拜访记录 → 记录会议内容和反馈
9. 推演模拟 → 启动推演 → 查看态度变化 → 调整策略
10. 商机概览 → 阶段检查 → 满足条件 → 推进阶段
```

### 4.2 会前准备与会后推演

```
会前：拜访预案 → 选择干系人 → 生成预案 → 审阅
会中：执行拜访
会后：拜访记录 → 填写会议纪要 → 关联任务
      推演模拟 → 选择会议纪要 → 启动推演 → 查看报告 → 虚拟采访
      工作台 → 盲区扫描 → 根据新发现调整行动
```

### 4.3 策略调整

```
推演模拟 → 发现态度下滑信号 → 虚拟采访深入了解
       → 盲区扫描 → 发现新的风险点
       → 行动建议 → 采纳新行动 → 执行
       → 重新推演 → 验证策略调整效果
```

## 5. 常见问题

**Q: 推演模拟中的态度变化会直接影响干系人数据吗？**
A: 不会。推演结果中的态度变化是模拟值，仅用于策略参考。如需修改干系人实际数据，请在干系人管理页面手动编辑并填写变更原因。

**Q: 盲区扫描支持自动执行吗？**
A: 支持。在 Agent 任务中配置定时扫描规则，系统可按 cron 表达式自动执行盲区扫描。

**Q: 如何合并重复的干系人？**
A: 在干系人列表页面，点击「合并」按钮，选择主干系人和被合并干系人，确认后系统将合并属性并保留变更日志。

**Q: 推演报告和虚拟采访的区别是什么？**
A: 推演报告是宏观的结构化分析（风险、机会、行动建议），虚拟采访是微观的第一人称角色扮演，用于深入了解特定干系人的想法。

**Q: 智能进化中的模式审核需要注意什么？**
A: 审核通过的销售模式会直接影响后续行动推荐的权重。建议定期审核候选模式，确保推荐质量。废弃的模式不会影响推荐。
