# SVS+Challenge Sales 销售框架完整指南

---

## 一、框架概述

### 1.1 什么是SVS+Challenge Sales？

SVS（Solution Value Selling，解决方案价值销售）与Challenger Sales（挑战者销售）是西门子数字化工业软件部门的两大核心销售方法论。

**两者的关系：**
- SVS是**流程框架**：定义"做什么"和"何时做"
- Challenger Sales是**互动技能**：定义"如何做"和"如何说"

**核心目标：**
成为客户信赖的顾问（Trusted Advisor），而非仅仅是供应商。

### 1.2 客户旅程

```
Land（落地）→ Adopt（采纳）→ Expand（扩展）→ Renew（续约）
```

### 1.3 核心价值主张

- 以解决方案为中心，而非单一产品
- 关注客户业务成果和价值实现
- 缩短价值实现时间（Time to Value）
- 驱动经常性收入（ARR）增长

## 二、SVS PEF 销售流程（前三个阶段）

### 2.1 阶段一：Account Orchestration（客户编排）

#### 2.1.1 目标与定位

**核心目标：** 建立客户关系，定位西门子为可信赖的顾问

**战略意义：**
- 随着向SaaS模式转型，西门子希望被客户视为可信赖的顾问
- AO推动经常性收入，使客户参与识别增长商机
- 管理续约以减少客户流失
- 与客户一起扩展，协调规模化

#### 2.1.2 关键角色与职责

| 角色 | 职责 |
|------|------|
| Account Orchestrator (AO) | 主导角色，负责创建、更新和执行客户计划 |
| Technical Account Manager (TAM) | 提供深度技术专业知识，担任战略顾问 |
| Portfolio Developer (PFD) | 识别与投资组合相关的线索和商机 |
| PreSales Consultant (PSC) | 提供技术支援，评估客户需求，识别西门子解决方案策略和定位 |

**关键洞察：**
- 如果没有TAM，PSC将承担技术顾问角色
- AO使用Digital Threads和Xcelerator Portfolio进行销售

#### 2.1.3 客户研究与了解

**如何了解客户？**

AO需要通过以下方式深入了解客户：

1. **公司结构图（Company Structure Map）**
   - 组织架构
   - 决策流程
   - 关键利益相关者

2. **关系图谱（Relationship Map）**
   - 与客户各层级的关系
   - 影响力网络
   - 沟通渠道

3. **客户战略图（Customer Strategy Map）**
   - 客户的业务战略
   - 市场定位
   - 竞争优势

4. **西门子目标与任务（Siemens Goals & Objectives）**
   - 我们在客户处的目标
   - 具体任务和行动计划

#### 2.1.4 关键活动

**日常活动：**
- 创建和更新客户计划（Account Plan）
- 识别潜在商机和线索（Suspects）
- 建立关系图谱（Relationship Map）
- 进行季度业务回顾

**季度业务回顾：**
- 保持团队完全对齐
- 更新最新的客户信息
- 准备持续的客户参与和满意度

#### 2.1.5 关键输入与输出

**输入：**
- 客户账户（Salesforce.com）
- 客户概况计划（ACP）
- 线索（Suspects）

**输出：**
- **客户计划（Account Plan）** - 这是关键交付物
  - 公司结构图
  - 关系图谱
  - 客户战略图
  - 西门子目标与任务

#### 2.1.6 "努力对齐"原则

**核心理念：** 所有团队的努力必须对齐

- 保持团队完全对齐、最新、准备就绪
- 推动持续的客户参与和满意度
- 客户详情必须保持最新

### 2.2 阶段二：Suspect Management（线索管理）

#### 2.2.1 目标与定位

**核心目标：** 识别和评估潜在销售商机

**战略意义：**
- 识别潜在销售商机
- 评估商机质量和可行性
- 确定是否进入下一步

#### 2.2.2 关键活动

**识别线索：**
- 识别潜在商机
- 评估商机质量和可行性
- 确定是否进入下一步

**PM10 - Bid/No Go决策：**
- 确认潜在商机
- 评估是否值得投入资源
- 决定是否进入下一阶段

#### 2.2.3 线索来源

**来自多个渠道：**
- Account Orchestration阶段识别的潜在商机
- 市场调研和行业分析
- 客户反馈和推荐
- 合作伙伴渠道

#### 2.2.4 评估标准

**商机评估维度：**
- 战略契合度
- 预期收入规模
- 竞争强度
- 资源需求
- 成功概率

#### 2.2.5 关键决策点

**PM10 - Bid/No Go决策：**
- 确认潜在商机
- 评估是否值得投入资源
- 决定是否进入下一阶段
- 如果决定不继续，AO保持商机在发现阶段并脱离接触

### 2.3 阶段三：Opportunity Orchestration（商机编排）

#### 2.3.1 目标与定位

**核心目标：** 选择合适的销售模式，成功落地和扩展商机

**战略意义：**
- 专注于选择合适的销售模式以成功落地和扩展商机
- 目标应该是选择能够最小化价值实现时间的销售模式
- AO评估商机并确定最佳销售模式

#### 2.3.2 销售模式选择

**三种主要销售模式：**

| 销售模式 | 适用场景 | 特点 |
|----------|----------|------|
| Inside Sales（内部销售） | 低复杂度解决方案，不符合金额门槛 | 快速、低成本 |
| Prescriptive Pursuit（规范性销售） | 客户要求遵循其招标流程时 | 遵循客户流程 |
| Value Solution Selling（价值解决方案销售） | 标准销售流程 | 完整的价值销售方法 |

**销售模式选择逻辑：**
- AO评估商机并确定最佳销售模式
- 如果解决方案复杂度低且不符合金额门槛，AO可能会与内部销售团队合作
- 如果客户要求遵循其招标流程，AO试图重新定位为规范性销售，但可能需要通过RFx流程

#### 2.3.3 关键角色与团队组建

**主要角色：**
- Account Orchestrator（AO）- 主导角色

**团队组建：**
- TAM（Technical Account Manager）
- EM（Engagement Manager）
- PreSales Solution Consultant
- Solution Architect

#### 2.3.4 关键活动

**销售策略制定：**
- 制定销售策略以赢得商机
- 解决风险
- 对齐价值实现时间
- 决定合作伙伴参与

**团队协作：**
- 与预售团队合作
- 使用Value Solution Selling
- 与TAM合作进行投标

#### 2.3.5 关键输入与输出

**关键输入：**
- Account Plan（来自Account Orchestration）
- Salesforce.com Opportunity
- Suspect Opportunity（可能）

**关键输出：**
- 商机计划（Opportunity Plan）
- 销售策略
- 团队组建

#### 2.3.6 商机计划

**商机计划内容：**
- 客户背景和需求
- 价值主张
- 销售策略
- 竞争分析
- 风险评估
- 行动计划

**商机计划与客户计划的关系：**
- Account Orchestration的主要交付物是客户计划
- Opportunity Orchestration的主要交付物是商机计划
- 商机计划可能独立于客户计划

#### 2.3.7 PM里程碑

**PM20 - Go/No Go决策：**
- AO、TAM、EM、PFD获得客户和西门子的初步利益理解
- 决定是否继续推进
- 组建商机团队

**PM30 - Pursuit Strategy Review（销售策略评审）：**
- 内部利益相关者对齐销售策略
- 对齐价值实现时间

**PM40 - Bid Approval（投标批准）：**
- 内部批准综合提案
- 法律、财务、收入确认等审批

**PM70 - Won or Lost（赢单/丢单）：**
- 验证合同文件已签署
- 商机进入Closed Won或关闭

## 三、Challenger Sales 挑战者销售模型

### 3.1 核心理念

**挑战者销售的本质：**
通过双向沟通以理性和情感说服的方式传达商业见解，颠覆客户思维模式，推动客户采取行动。

**四大核心能力：**
1. 营造积极的紧迫感（Creating Positive Urgency）
2. 通过商业见解教育客户（Commercial Teaching）
3. 根据客户定制沟通信息（Tailoring）
4. 掌控局面，促进行动（Taking Control）

### 3.2 营造积极的紧迫感

**定义：** 推动客户采取行动的生产力，源自与客户一起探讨的陌生或未知主题。

**紧迫感刻度盘：**

| 状态 | 特征 |
|------|------|
| 毫无紧迫感 | 放松，无需采取行动 |
| 紧迫感（负面） | 紧张，拒绝听取新的意见，拒绝采取行动 |
| 积极的紧迫感 | 激起兴趣，需要采取行动 |

**营造方法：**
- 深入挖掘客户的看法和设想
- 提出有力的问题（Open-ended questions）

**开放式问题示例：**
- 什么...？
- 怎样...？
- 何时...？
- 在哪...？
- 谁...？
- 为什么...？

**有力问题的作用：**
- 建立信任
- 让人感觉不那么有胁迫性
- 允许自由回应
- 获得有关话题或形势的额外信息
- 引出其他观点和主张

### 3.3 通过商业教育形成差异化优势

**传统销售言辞 vs 商业指导：**

| 传统销售言辞 | 商业指导 |
|--------------|----------|
| 首先展示您的独特优势 | 开始：先说对客户业务的忧虑 |
| 以公司简介开场 | 中间：探讨维持现状的真正成本 |
| 讨论您可以创造的价值 | 最后：引出您的独特解决方案 |
| 最后要求客户向您购买产品 | |
| 强调为客户创造的价值（80%供应商为中心） | 80%客户为中心 |
| 确认痛点或战略目标 | 告知客户不解决问题会产生哪些相关成本 |

**有效商业指导步骤：**

```
A. 界定现状 → 确定不足之处 → 确定新方法 (B)
     ↓              ↓              ↓
为什么改变？    为什么是现在？    为什么是我们？
     ↓              ↓              ↓
让客户换种方式思考 → 引出您的解决方案 → 促使行动
```

**商业指导组成要素：**
1. 分享重构（Reframe）
2. 介绍影响（Rational + Emotional Impact）
3. 展示价值（New Way Forward）

**重构思维标准：**
- 出其不意：必须超出预料
- 具有规模：必须值得解决
- 具有可行性：必须最终能够引回到您的解决方案

**影响的两个维度：**
- **理性影响：** 业务指标（收入减少、风险增加、开支增加）
- **感性影响：** 讲述事例、个性化、人性化对待问题

**3-3-3分析法：**
- 3个客户行业的重大变化
- 3个客户企业的重大目标
- 3个客户当前为解决问题而采取的措施

**SWOT分析：**
- 强项（Strengths）
- 弱点（Weaknesses）
- 商机（Opportunities）
- 威胁（Threats）

### 3.4 针对客户定制沟通信息

**量身定制的四个视角：**

| 视角 | 内容 |
|------|------|
| 行业视角 | 当前行业新闻头条、行业趋势、行业风险 |
| 公司视角 | 公司的竞争方式、客户为何选择本公司、战略目标 |
| 角色视角 | 在公司的高度、职能重点、业务优先级 |
| 个人视角 | 业务/专业目标、交流风格、对西门子的亲和力 |

**利益相关者分类：**

| 类型 | 特征 | 影响力 |
|------|------|--------|
| 善于鼓动的人 | 寻求合理程度的怀疑，从大处着眼，说话时以"我们"代替"我" | 1.0x（最高） |
| 乐于交谈的人 | 平易近人且乐于分享信息，以自己为中心 | 0.89x |
| 阻碍变革的人 | 坚信稳定本身就是目标，很少帮助供应商 | 0.23x |

**关键洞察：**
- 销售人员若能打动善于鼓动的人，则取得优秀业绩的概率高出31%
- 商业见解是打动善于鼓动的人的唯一途径

**社交风格：**

| 风格 | 特征 | 期望 |
|------|------|------|
| 分析型 | "让我好好想一想" | 准确、逻辑、事实 |
| 推动型 | "我们采取行动吧" | 高效、结果、时间 |
| 亲和型 | "我们一起来讨论这个问题" | 和蔼可亲、关系、认可 |
| 表达型 | "让我把对这个问题的想法告诉您" | 幽默、想法、掌声 |

### 3.5 掌控局面，促进行动

**掌控局面的定义：** 在整个采购流程中主动引导客户采取建议的行动。

**为什么需要掌控：**
- 客户实际采购时长超过预期
- 被动响应会延长销售周期
- 主动引导可以缩短销售周期

**掌控的方法：**
1. 关注认可要素（Validation Factors）
2. 通过有力的请求进行引导

**认可要素：**
客户对销售互动的反应，表明客户准备并愿意推进交易。

**认可要素的三个问题：**
1. 这是一项客户驱动的措施吗？
2. 如何证明这项措施推动客户兑现承诺？
3. 有何证据表明客户遵守了自己的承诺？

**有力的请求（Powerful Ask）：**

| 要素 | 说明 |
|------|------|
| 为何重要 | 说明为什么这个行动是必要的 |
| 何时需要 | 明确时间要求 |
| 需要谁提供 | 确定责任人 |
| 您需要什么 | 明确具体需求（不做任何修改或保持沉默） |

**有力的请求示例：**
```
"我们发现一个可以为您提高效率和收益的绝佳商机，并决定由Dave和Lauren帮助您分析我们当前的建议。
我们在更新推荐的方法前需要收集更多数据，所以我们需要在下周二安排一次会面。
我们查看一下各自的日程，然后确定一个适合所有人的时间。"
```

**掌控的关键活动：**
- 设置和管理最后期限和里程碑
- 确认协议并继续
- 确定并吸引所有相关利益相关者
- 识别并克服障碍
- 必要时使用强有力的请求来确认协议
- 早输（优先考虑高潜力交易）

## 四、SVS与Challenger Sales的整合应用

### 4.1 整合框架

```
SVS流程阶段          Challenger Sales技能
─────────────        ─────────────────────
Account Orchestration → 营造积极的紧迫感
        ↓                      ↓
Suspect Management   → 通过商业教育形成差异化
        ↓                      ↓
Opportunity Orchestration → 根据客户定制沟通信息
        ↓                      ↓
Value Solution Selling → 掌控局面，促进行动
```

### 4.2 Vision Setting（愿景设置）

**愿景设置的七步法：**

1. **The Warmer（热身）：** 与客户建立关系，赞美最近的收购或成功的产品发布
2. **The Reframe（重构）：** 呈现问题："这是您问题背后的问题"
3. **Rational Drowning（理性冲击）：** 提出理性案例
4. **Emotional Impact（感性冲击）：** 提出感性案例
5. **A New Way Forward（新方法）：** 呈现解决方案："这就是您解决问题的方法"
6. **The Siemens Solution（西门子解决方案）：** 展示解决问题所需的工具和实践
7. **Call to Action（行动号召）：** 提出下一步

**Big Picture愿景的核心：**
- 不要过早提及具体解决方案名称
- C-level高管对新术语不感兴趣
- 他们想听到关于业务的见解和我们如何解决问题

### 4.3 Comprehensive Proposal（综合提案）

**综合提案的三个组成部分：**

| 组成部分 | 说明 | 负责人 |
|----------|------|--------|
| 软件报价 | 客户购买的软件报价 | Account Orchestrator |
| 工作说明书 | 如何实施和推动解决方案采纳 | 团队 |
| 草稿CSP | 指导文件，详述成功是什么以及如何实现和衡量 | 团队 |

**为什么一起呈现：**
- 不仅呈现软件成本，还呈现软件带来的价值
- 在价值的背景下呈现价格
- 减少客户谈判空间
- 谈判时也讨论价值影响

**呈现综合提案的关键点：**
- 必须在PM40投标评审后才能呈现
- 需要安排与客户关键决策者的会议
- 会议应遵循草稿CSP的结构
- 信息不应是新的，是获得集体同意的商机
- 没有演示（Demo），是管理层面的对话

### 4.4 Customer Success Plan（客户成功计划）

**CSP的四大章节：**

1. **成功是什么样子：** 业务用例、预期价值、业务流程、所需解决方案
2. **如何实现成功：** 实施计划、采纳计划
3. **如何衡量成功：** 采纳指标（技术使用）、性能指标（流程改进）
4. **治理：** 客户和西门子如何合作实现以上目标

## 八、案例分析：万向一二三PLM选型

### 8.1 案例背景

万向一二三是一家新能源电池企业，正在考虑PLM（产品生命周期管理）系统选型。西门子使用SVS+Challenge Sales方法进行销售。

### 8.2 挑战者销售应用

**第一步：激发共鸣（Warm Up）**
- 行业前十的电池企业已实现研发-制造-供应链数据实时联动
- 万向当前手工传递BOM表的方式可能导致交付延期和隐性成本上升

**第二步：诊断痛点（Uncover the Pain）**
- 设计数据分散在Excel/邮件中，版本混乱导致返工率
- 跨部门协作依赖人工沟通，需求传递误差率
- 物料编码未统一，导致物料重复采购
- 因流程低效导致的年均损失超8000万元

**第三步：冲击现状（Challenge the Status Quo）**
- PLM仅作为文件管理工具，但电池创新竞争本质是研发效率的战争
- 竞品比您早3个月推出高能量密度电池，可能直接失去车企下一代车型的定点资格
- 手工管理BOM导致供应链采购误差

**第四步：激发情绪**
- 行业失败案例
- 引用数据：西门子PLM用户5年内TCO比达索低18%，比PTC低12%

**第五步：新方法**
- 缩短产品上市周期
- 支持全球化协同
- 提升合规性

**第六步：西门子方法**
- "万向一二三的估值取决于技术领先性，而技术领先性取决于研发效率——PLM是效率战争的'弹药库'"
- "选择西门子不是买软件，而是引入一套让车企愿意为'万向电池'支付溢价的能力体系"

### 8.3 SVS流程应用

**价值重构：**
- 将客户关注点从"初期低价"转向"长期价值"
- 利用西门子技术生态与TCO优势，重塑决策逻辑

**竞品分析：**
- 达索：封闭生态，高成本
- PTC：技术分散，投入不足

## 十、总结

SVS+Challenge Sales框架是一个完整的销售方法论，结合了：
1. **SVS PEF** - 提供从客户发现到商机管理的完整流程框架
2. **Challenger Sales** - 提供与客户互动的具体技能和方法

**成功的关键：**
- 成为客户信赖的顾问，而非仅仅是供应商
- 以解决方案为中心，关注客户业务成果
- 缩短价值实现时间
- 驱动经常性收入增长
- 持续应用Challenger技能，颠覆客户思维模式
- 营造积极的紧迫感，推动客户采取行动

**最终目标：**
通过规范性销售，重点关注价值实现时间，确保续约，成为客户业务增长的战略合作伙伴。
